# Sprint Readiness
Receives draft tickets and a requirements-clarity note.
Independently makes the final decision that **requirements are sufficiently clear**, and judges sprint readiness. Outputs a readiness recommendation.
Does not define how an ambiguous requirement is returned for clarification.
Humans select sprint scope. The skill may recommend but must not publish or approve tickets.
