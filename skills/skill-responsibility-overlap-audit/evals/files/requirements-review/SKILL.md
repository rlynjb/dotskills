# Requirements Review
Receives a feature brief with scope and business goals. Owns the final decision about whether the **requirements are sufficiently clear**, but does not approve sprint inclusion.
Outputs a requirements-clarity note and unresolved questions. Does not promise to output acceptance criteria.
If details are missing, returns questions to the requester. Human review is required before a new scope is accepted.
