# Evidence Refinement
Starts from a feature idea or ticket and produces a complete evidence-backed requirements clarification report without a product brief.
If a product brief is voluntarily supplied, the skill may use it as optional context to compare goals and requirements with available implementation evidence.
It does not own product intent and does not change or publish the brief.
It reports proposed changes and unresolved questions to the product-brief owner for review. It never automatically invokes Brief Planning.
