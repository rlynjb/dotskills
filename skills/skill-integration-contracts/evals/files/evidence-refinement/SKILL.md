# Evidence Refinement

Starts with a feature idea or ticket, with or without an existing product brief. If the user voluntarily supplies a product brief, use it as optional context with its source and unresolved questions.

Produces an evidence-backed requirements clarification note and proposed wording changes. Does not own product intent, alter upstream artifacts or approve scope changes. Returns proposed updates to the product owner for confirmation.

No automatic skill dispatch and no access to publishing tools are documented.
