# Ticket Construction

Produces draft tickets and acceptance criteria based on confirmed, adequately scoped requirements. Approved requirements and a responsible reviewer are REQUIRED before publication; if approval is absent it may produce provisional drafts clearly labeled NOT APPROVED, but must not publish.

If requirements are unclear, return questions to the requirements owner. Does not make upstream scope decisions, and requires human review before any tickets are published.

Does not automatically invoke another skill.
